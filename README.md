## GitHub → Cloudflare Pages
Upload index.html, assets, robots.txt and _headers at the repository root.
Create a Cloudflare Pages project connected to this business GitHub repository.
Framework: None. Production branch: main. Build command: leave empty.
Build output directory: /. Root directory: leave blank.
No dependencies, API keys, paid hosting or build step are required.

## Required after first deployment
Send the exact working Cloudflare Pages URL back for final URL configuration.
Add an absolute canonical link, og:url, og:image and twitter:image using that URL.
The bundled social-preview.png is ready; its metadata needs the final absolute URL.
Create sitemap.xml containing that canonical homepage URL and add its absolute URL to robots.txt.
Update Person structured data with the canonical url and portrait image URL.
If a custom domain is planned, use it as the canonical address and redirect the old address.

## Google Search Console
Add and verify the final site using the verification method Google offers.
For a Pages subdomain, URL-prefix verification can use an HTML verification file or meta tag.
For an owned custom domain, domain verification normally uses a DNS record.
Upload the actual verification file or token provided by Google; none is invented or included here.
Submit sitemap.xml and inspect the homepage URL to request indexing.
Indexing and ranking are controlled by Google and are not guaranteed.

## Final live checks

CV download, email, phone and LinkedIn links. Email opens the visitor's mail app;
there is no contact form or backend. External profile availability must be checked live.

No tracking or analytics scripts are installed. Search Console does not require Google Analytics.
